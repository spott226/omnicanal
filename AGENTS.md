# Regla operativa para Codex

Antes de iniciar cualquier fase de este proyecto, lee primero:

- `README_MVP_FASES.md`
- `docs/MVP_SIMPLIFICATION_RULES.md`

Trabaja siempre por fases pequeñas. No agregues funciones fuera del MVP. No elimines planes, suscripciones, prueba gratuita, selección mensual/anual ni estructura de Stripe. No conectes Meta, IA real o Stripe real sin que el usuario lo autorice explícitamente.

Antes de cambios grandes:

1. Confirma que estás en la rama `mvp-simplificado`.
2. Revisa impacto en frontend, backend, base de datos y rutas afectadas.
3. Evita migraciones destructivas.
4. Ejecuta validación proporcional al cambio.
5. Entrega qué cambió y qué debe probar el usuario.
