# Plan de producción

La Fase 1 establece PostgreSQL, Prisma, API NestJS, autenticación, roles, aislamiento multiempresa, seed demo y preparación de infraestructura.

Fases posteriores, sin avanzar todavía:

2. Agente de IA real.
3. Automatizaciones y calendario.
4. Infraestructura de Meta.
5. WhatsApp.
6. Instagram y Facebook.
7. Planes y control de consumo.
8. Seguridad y producción.
9. App Review e incorporación de clientes.

La Fase 1 solo se cierra después de ejecutar migración y seed sobre PostgreSQL vacío, validar dos organizaciones reales aisladas, conectar todas las mutaciones de la interfaz, ejecutar pruebas completas y confirmar builds web/API.
